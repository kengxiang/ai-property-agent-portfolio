# Proposed licensing scope

This repository currently has no project license. MIT is the preferred option for project-owned application code, documentation, tests and scripts, subject to the owner's approval and a contributor rights check. Confirm that the owner can license the synthetic CSV and the six PDFs generated by the repository before including them in that scope.

Python dependencies are installed separately. Their terms include MIT, BSD, Apache-2.0 and LGPL-3.0 for psycopg. The repository references n8n's upstream container, which has separate Sustainable Use and Enterprise terms. Ollama downloads model artifacts separately. The Qwen3.5-4B upstream model card identifies Apache-2.0 and the BGE-M3 model card identifies MIT. Check the exact artifacts and notices before distributing images, dependency bundles or model weights. Google controls Gemini API use through its provider terms.

The proposed project license would cover only material the owner approves. After approval, add the full MIT text with the approved copyright holder and year. Preserve relevant third-party notices and state any fixture or asset exclusions.
